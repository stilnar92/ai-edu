# LLM course materials — used inside Codex

The learning interface is the Codex chat. Do not start a website or browser for this course unless the learner explicitly requests it.

Resume at **BPE vocabulary construction**, the earliest substantive gap. Keep the later chat progress; do not restart everything.

## Files to use

- `COURSE_PLAN.md`: source-linked syllabus and original teaching workflow.
- `PROGRESS.md`: evidence of prior understanding and unfinished topics.
- `materials/bpe-interactive.html`: inline interactive experiment, rendered in the Codex conversation.
- `materials/03-bpe.md`: readable lesson notes.
- `materials/04-real-tokenization.md`: a real tokenizer applied to text, with a runnable script.
- `mini-model/README.md`: the running tiny-model project and its incremental plan.
- `source/transcript.txt`: original source material.

Explain in chat, render the relevant inline experiment, ask one focused question, give an exercise, and ask whether to proceed or clarify. Prepare future materials as they are reached. Update the progress record after substantive learning, not just assent. Review each major section before proceeding.

The source line ranges are approximate editorial study ranges, not timestamps. BPE intentionally overlaps the tokenization range. Auto-generated subtitles may contain mistakes. Historical claims are not current recommendations.

The initial standalone browser prototype was removed after the interface requirement was clarified. No site was published.
