# Source

The lesson plan refers to line ranges in `transcript.txt`, the auto-generated subtitles of Andrej Karpathy's video [Deep Dive into LLMs like ChatGPT](https://www.youtube.com/watch?v=7xTGNNLPyMI). The transcript belongs to its author and is not included in this repository.

Watch the video directly, or save its subtitles here as `transcript.txt` if you want the line ranges to resolve. Line numbers depend on how the subtitles were exported, so treat the ranges as approximate.
